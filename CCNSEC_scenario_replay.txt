# covers all 6 combinations exactly once (2 and 3 are coprime).

#   3: antiReplay/13      4: integrityOnly/27  5: antiReplay/41
#
# CCNSecurity.enabled=true and policy=reject are FIXED in both columns -
# the only thing that differs is replayCheckEnabled (Experiment 5 vs 6).
# No forging in this file at all (numOfMsgToGenerate=0 below) - the
# attacker's only activity is capture-and-replay.
